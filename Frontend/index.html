Beginner Introduction

What you will see in the simulator

Kanban is a simple way to visualize work. Instead of hiding tasks in a list, a Kanban board shows where each task is in the workflow.

The columns represent steps such as planning, development, review, testing, and done. Task cards move from left to right as work progresses.

Work in Progress, or WIP, means the amount of work currently being handled. WIP limits help teams avoid starting too many tasks at the same time.

This simulator demonstrates how tasks flow through a board, how capacity affects progress, and how bottlenecks can appear when too much work is active.

Kanban in this simulation

  • Columns show workflow stages.
  • Cards show single pieces of work.
  • Progress bars show how far a task has moved in its current step.
  • Metrics show time, completed tasks, and current workload.
